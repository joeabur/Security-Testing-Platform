# Third-party components

Every tool this platform integrates or adapts, with its licence and how it is
used. Exact pinned versions for the Python dependencies are in
`backend/pyproject.toml` and the lock file; the SBOM (CycloneDX) generated by
`.github/workflows/sbom.yml` is the authoritative machine-readable list.

## Licence compatibility

This project is Apache-2.0 (`docs/decisions/0004-licence.md`). The runtime
dependencies above are permissive and compatible.

Semgrep's CLI is LGPL-2.1 and Hypothesis is MPL-2.0 — both weak copyleft, both
used as **separate processes or unmodified libraries**, which is the usage those
licences are written for. Neither is modified or statically linked. If you
redistribute a modified Semgrep or Hypothesis, their terms apply to that
modification, not to this project.

Redis's server licence (RSALv2/SSPLv1) applies to running Redis, not to software
that connects to it. This project ships no Redis binary.

The platform's own licence engine (`docs/supply-chain.md`) can be pointed at
this repository, and this table is a reasonable thing to check it against.
